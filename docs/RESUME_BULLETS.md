# Resume wording

**INTC Short Put Backtesting Engine | Python, pandas, NumPy, matplotlib**

## Recommended English version

- Built a Python backtesting engine for cash-secured INTC puts using 2,011 daily price observations (2018–2025), American binomial option pricing, and lagged volatility estimates.
- Modeled daily mark-to-market P&L, cash collateral, transaction costs, and physical assignment; compared expiry and 40% crash scenarios and generated annual P&L and drawdown reports.
- Validated pricing and cashflow accounting with automated tests, including assignment reconciliation, capital constraints, and look-ahead checks; packaged reproducible data, charts, and a command-line workflow.

## Compact one-bullet version

- Developed a Python INTC short-put simulator covering 2,011 trading days, with American option pricing, daily P&L and collateral accounting, assignment stress tests, and reproducible risk reports.
