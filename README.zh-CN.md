# INTC 卖出看跌期权回测

使用 Python、pandas、NumPy 和 matplotlib 构建的量化研究项目。
真实 INTC 日线覆盖 **2018-01-02 至 2025-12-31，共 2,011 个交易日**。
期权权利金来自美式二叉树模型，并非历史期权成交报价。

## 如何运行

安装 Python 3.11 或以上，在本项目目录打开终端：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m intc_put
python -m pytest -q
```

Windows PowerShell 的环境激活命令为 `.venv\Scripts\Activate.ps1`。
安装依赖后，默认回测使用已有 CSV，可离线运行。
全部结果写入 `reports/`。完整参数、公式、来源和限制见 [英文 README](README.md)。

## 策略做了什么

1. 初始资金 $10,000，每次卖出 1 张 put，对应 100 股。
2. 用上一交易日收盘价的 95% 向下取整确定行权价；到期约 30 个日历日。
3. 用滞后 20 日历史波动率，通过 100 步美式二叉树估算权利金和每日负债。
4. 用全额现金担保接股，逐日记录现金、股票、期权负债、浮动盈亏和保证金占用。
5. 到期股价不低于行权价，期权失效；低于行权价则按行权价支付现金并接收股票。
6. 接股后再持有 5 个交易日卖出，考虑手续费和滑点；持仓期间不开新 put。

**收到权利金不等于立刻盈利**。净值 = 现金 + 股票市值 − 期权负债。
现金担保金额是冻结资金，不会被重复扣成费用。指派接股造成的损失也不会重复计入。

## 需要能够解释的限制

- 历史波动率不等于隐含波动率；模型未使用真实期权链、买卖价差和可成交报价。
- 行权价和到期日为模拟规则，未保证存在对应的真实上市合约。
- 美式模型允许提前行权估值，但交易引擎只模拟到期指派。
- 假设利率固定、股息率为零；未计入股息收入、现金利息、税费和真实结算延迟。
- 日线无法反映盘中浮亏、流动性冲击及所有执行风险。
- 卖 put 收益上限有限，股价暴跌可能使亏损远超权利金；全额现金担保不能消除价格风险。

项目重点是可解释的记账、风险建模和复现能力，不是证明策略稳定赚钱。
